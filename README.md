# Demo funcional Raíces Vivas — Sprint 1

Incluye exploración, filtros, detalle, disponibilidad, solicitud de reserva, validación de cupos, confirmación con estado Pendiente y consulta de solicitudes.

## Abrir localmente
Abra `index.html`.

## Publicar
Suba la carpeta completa a Netlify Drop, GitHub Pages o Vercel.

## Nota
Es un prototipo frontend. La persistencia se simula con `localStorage`; no utiliza backend real.
